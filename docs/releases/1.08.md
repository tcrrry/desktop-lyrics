# 桌面歌词 1.08

## 新增功能

- 发音：QQ／网易云官方发音轨，独立开关；覆盖展开、收起与全屏歌词，兼容逐字与译文。发音在上、原文居中、译文在下；发音与译文同字号、同亮度，收起窗口一行显示原文，两行显示原文＋译文，开启发音且达到三行高度时显示全部，关闭发音时最多两行。
- 描边：自动对比色细描边，白色歌词在浅色背景上仍可辨认；展开与收起分别记忆。
- 快捷入口：下拉快捷面板“桌面歌词”磁贴，点击开关悬浮窗。
- 两行设置入口均采用 2:8 排布，描边与发音按钮尺寸及红白胶囊动画一致。

## 验证与发布

发布前需要原 Release 签名，以保证可直接覆盖 1.07；不要用新密钥替代。Debug 测试包使用独立 `.dev` 包名，不会覆盖正式版。

真机需验证：vivo 面板添加磁贴与缺权限引导、前台/后台/锁屏开关、QQ/网易云日语和韩语发音、没有发音数据的歌曲、浅色背景逐字描边、展开/收起/全屏切换和设置持久化。

本地验证：Debug/Release 构建、9 项平台发音单元测试、Android lint、匹配记忆与发音显示 Node 回归测试均通过。浏览器检查覆盖逐字高亮、三层顺序、发音与译文同亮度，以及收起窗口 1/2/3 行切换。正式发布仍待原签名和真机验证。
