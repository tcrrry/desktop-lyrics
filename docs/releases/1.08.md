# 桌面歌词 1.08

## 新增功能

- 发音：QQ／网易云官方发音轨，独立开关；覆盖展开、收起与全屏歌词，兼容逐字与译文。发音在上、原文居中、译文在下；发音与译文同字号、同亮度，收起窗口一行显示原文，两行显示原文＋译文，开启发音且达到三行高度时显示全部，关闭发音时最多两行。
- 描边：自动对比色细描边，白色歌词在浅色背景上仍可辨认；展开与收起分别记忆。
- 快捷入口：下拉快捷面板“桌面歌词”磁贴，点击开关悬浮窗。
- 两行设置入口均采用 2:8 排布，描边与发音按钮均与右侧胶囊同高、大小固定，关闭时采用相同深色背景，开启时采用白红渐变，移除伸缩动画。

2026-10-03 同版本修订：保留 1.08 / versionCode 108 与原签名，替换原发布 APK。用户确认快捷磁贴已出现在系统待添加区，本次保留其现有实现。

## 验证与发布

正式 APK 已使用原 Release 密钥签名，签名证书 SHA-256 与 GitHub 1.07 APK 完全一致，可直接覆盖升级。生产包为 `com.tcrrry.desktoplyrics`、`versionName 1.08`、`versionCode 108`、`arm64-v8a`。

本地发布时没有 ADB 设备在线，因此没有新增 vivo 真机验证结论。后续可继续验证：面板添加磁贴与缺权限引导、前台/后台/锁屏开关、QQ/网易云日语和韩语发音、没有发音数据的歌曲、浅色背景逐字描边、展开/收起/全屏切换和设置持久化。

发布验证：干净 Release 构建、9 项平台发音单元测试、Android lint、匹配记忆与发音显示 Node 回归测试均通过；`apksigner` 验证 APK v2 签名有效且证书与 1.07 一致。浏览器检查覆盖逐字高亮、三层顺序、发音与译文同亮度，以及收起窗口 1/2/3 行切换。
